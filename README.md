## ✨ 产品简介

写一篇有深度的长文，难不在于文笔，难在于**把想说的想清楚**。

**LucidWrite** 是一款**本地运行**的 AI 写作工作台，专为严肃的长内容创作者设计。它将写作全流程拆解为七个清晰阶段：

1. 💡 **选题交互**
2. 🗂️ **大纲框架**
3. ✍️ **初稿敲定**
4. 🔍 **内容精修**
5. ✅ **事实核查**
6. 📊 **质量评分**
7. 📤 **终稿输出**

**每一步由专属 AI Agent 负责**，让你始终掌控节奏，而非被 AI 替代思考。

所有草稿和附件均保存在**本地目录**，以 **Markdown 格式**输出，可直接 `git commit` 或外部编辑，数据自主可控。同时支持 **DeepSeek、OpenAI、Anthropic、Google** 等主流大模型，自由切换，不被平台绑架。

此外，LucidWrite 可学习你历史文章的语气与风格，让 AI 真正成为你的**长期写作搭档**，而不只是一次性生成工具。
